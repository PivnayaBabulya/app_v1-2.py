## **Проект «Учёт книг»**
этот проект основан на создании приложения, через которое можно выдавать книги пользователям, возвращать их и вести подсчёт того, сколько книг выдано и сколько возвращено

## так что же здесь можно в деталях?
- пользователи могут выбирать книги любых жанров
- при вводе в терминале "1" программа выдаёт ему 1 книгу
- <img width="270" height="47" alt="image" src="https://github.com/user-attachments/assets/d1db0b40-6d0f-45ae-87e6-c0a89530c004" />

- при вводе в терминале "4" программа возвращает 1 взятую книгу
- <img width="152" height="46" alt="image" src="https://github.com/user-attachments/assets/bdd5b913-344b-4e55-9082-f90b8b15d4b8" />

- при вводе администратором "2" ему предоставляется количество уже выданных пользователям книг
- <img width="146" height="48" alt="image" src="https://github.com/user-attachments/assets/caa391a8-6385-4682-a81c-5c679e3a9768" />

- при вводе администратором "3" программа сбрасывает счётчик и возвращает количество выданных книг к 0
- <img width="243" height="45" alt="image" src="https://github.com/user-attachments/assets/ce919916-ca9b-4aa4-b7b9-220ae656daf4" />

- при вводе "0" программа прекращает свою работу и "засыпает" до следующего запуска
- <img width="308" height="45" alt="image" src="https://github.com/user-attachments/assets/daa20a0d-c171-4d4f-9b57-db2df1c50878" />
